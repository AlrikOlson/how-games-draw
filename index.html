This is a set of pages that explain how a game draws its picture, one idea at a time. Every page has demos you can drag and poke at, so you see the trick working instead of reading about it. Each idea starts in plain words, then shows you what to try, then gives the real math and the real code for when you want them.

Two things to know

The timing numbers on these pages (milliseconds, memory, bandwidth) are rough estimates unless a source is named right next to them. Engines, games and papers are named only where the author was sure; otherwise the page just says "many engines".

The demos are flat, 2D versions of 3D techniques, built that way on purpose so you can see the moving parts: a strip of pixels instead of a full screen, an outline instead of a mesh, a side view instead of a camera cone. The math and code shown are the real 3D forms.
